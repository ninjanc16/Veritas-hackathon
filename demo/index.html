        Settings: live data

        The scan runs on saved output. These switches let this page pull newer readings while it is open. Keys are kept in this browser only and are never written to the project files.

        Where to get keys, and the conditions

        • USGS Water Data API. Free key at api.waterdata.usgs.gov/signup, sent by email. Works without a key at a lower limit. Send the key in the X-Api-Key header. The old waterservices.usgs.gov service is being retired.
        • USGS gauges that work. Only two USGS gauges on the Rio Grande in Texas report live flow: 08374550 (near Castolon) and 08375300 (Rio Grande Village). Both are in Big Bend, upstream of the canal districts. Checked on November 14, 2026.
        • Water Data for Texas. No key, but its server does not let a web page read it directly. A scheduled job downloads the reservoir files once a day and publishes them with this page's data. Readings are best estimates and carry no warranty.
        • U.S. Drought Monitor. Updates weekly, so the forecast, canal classes and sealant plan can only change weekly. The same scheduled job reruns the model when a new week is out.
