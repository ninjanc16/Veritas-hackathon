How to use it

Read the situation

The tiles above give this week's drought state for the 14 Texas counties within 50 km of the river, and current storage in the Amistad-Falcon system.

Explore the map

Drag to pan. Use the buttons, or Ctrl and scroll, to zoom. Hover any canal, county or reservoir for its record.

Run the basin scan

The scan assembles hydrography, the conveyance network, soil texture, drought class and the forecast, then ranks canal segments by inspection priority and assigns each one to its irrigation district.

Act on it

Set a budget in the sealant plan to see which district would treat which canals. Use the cost section to size the losses and the contacts section to reach the bodies that decide on canal work and aid.
